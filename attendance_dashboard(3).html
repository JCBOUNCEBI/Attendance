👥 Load Employee Data

Employee names can't be fetched directly from a local HTML file due to browser security.
Choose one of the two options below.

1
Open your Google Sheet → go to the Employees tab → press Ctrl+A then Ctrl+C
2
Click the box below and press Ctrl+V to paste, then click Load
1
In your Google Sheet, go to Extensions → Apps Script and create a new script called CorsProxy
2
Paste this code and click Deploy → New deployment → Web App → Anyone → Deploy
function doGet(e) { const id = '1S10jojUGnglMcxLtIwrKiNJe0ftW_IHPZA2vwEFPx-s'; const sheet = SpreadsheetApp.openById(id).getSheetByName('Employees'); const data = sheet.getDataRange().getValues(); const csv = data.map(r => r.map(c => '"' + String(c).replace(/"/g, '""') + '"').join(',')).join('\n'); const output = ContentService.createTextOutput(csv); output.setMimeType(ContentService.MimeType.TEXT); return output; }
3
Copy the deployment URL and paste it below — it's saved in your browser for next time
✓ Saved!
